# Porsche Motorsport Web

An independent, static web project dedicated to showcasing Porsche Motorsport news, iconic model specs, active racing teams, and official merchandise.

[🚀 View Live Site](https://renzosantelli.github.io/Porsche-Motorsport-Web/)

---

## 📌 Project Overview

This project is a multi-page web application designed to deliver a smooth browsing experience for Porsche Motorsport enthusiasts.

### What you can do:
* **News & Overview:** Explore the latest updates on Porsche's racing programs.
* **Garage / Models:** View detailed specs on models like the 911 GT3 RS, 911 GT3 R, and 963 Hypercar.
* **Teams:** Discover official and customer racing teams (e.g., Porsche Penske Motorsport, Manthey Racing).
* **Shop:** Browse featured Porsche Motorsport merchandise.
* **Seamless Navigation:** Switch across all sections without page breaks using standardized static routes.

### Limitations:
* **Static Content:** Content is currently hardcoded in HTML/CSS and does not fetch real-time live data via API.
* **No Dynamic Checkout:** The shop section serves as a showcase UI and does not process actual transactions.
